# Personal Portfolio Website

Personal portfolio website built to present my professional background, experience, projects, and technical skills.

The project is built with Next.js and TypeScript, using reusable components and centralized data for portfolio content.

## Live Website

https://tamilarsen-dev-portfolio.vercel.app

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- MDX

## Features

- Responsive portfolio interface
- Professional profile and experience
- Project showcase
- Technical stack overview
- MDX-based engineering notes
- Responsive navigation and UI components
- SEO and Open Graph metadata

## Getting Started

Clone the repository:

```bash
git clone https://github.com/tamilarsen-dev/tamilarsen-dev-portfolio.git
cd tamilarsen-dev-portfolio
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm run dev
```

Open http://localhost:3000 in your browser.

## Project Structure

```text
src/
├── app/           Application routes, pages, and styles
├── components/    Reusable UI and application components
├── data/          Portfolio and site configuration data
├── hooks/         Reusable React hooks
└── lib/           Utility functions and data access logic

content/           MDX writing content
public/            Static assets
```
